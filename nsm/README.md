# NSM (Nitro Security Module)

This package talks to the Nitro Security Module of a Nitro Enclave: attestation documents,
PCRs and entropy. It follows the request and response model of the official
[Rust NSM API](https://github.com/aws/aws-nitro-enclaves-nsm-api).

# Credits

The driver is derived from [hf/nsm](https://github.com/hf/nsm) by Stojan Dimitrovski.
